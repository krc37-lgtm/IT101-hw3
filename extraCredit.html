Web Development Guidelines

5 Practices You Should Do
  • Ensure High Contrast: Keep text clear against background colors.
  • Implement Responsive Design: Make sure layouts can adapt fully to mobile for ease of access.
  • Prioritize Fast Loading: Optimize structureal image file sizes.
  • Maintain Clean Hierarchy: Organize layouts for clean text and clean header tags.
  • Include Accesible Alt Text: Provide description for images.

      • 5 Practices You Should Avoid

      • Avoid Auto-playing Media: While its a neat idea, if people use your site often it gets tedious to manually mute it everytime.
      • Avoid Overwhelming Colors: Too many colors cause the focal point to mesh with everything else in a bad way and takes away from the site.
      • Avoid Hidden Navigation: Don't bury links behind confusing menus unless thats the point, otherwise a generally bad idea for daily use of services.
      • Avoid Missing Link Indicators: Make Sure links look different from plain text so users can instinctually grasp that is what they need to click/tap.
      • Avoid Fixed size: Its fine when you primarily want a site to be read on a larger device but otherwise limits convenience and expansion to smaller devices that users primarily use.
